Skin Nebula — demo animada

Board + pareja de fichas · Mainboard Override · artefacto procedural (generate_nebula.py)

La ficha se rotó 90° con CSS (el artefacto es vertical, como en el juego).
Haz clic en cualquier ficha para girarla · pasando el cursor se eleva con halo violeta.
Pips, LEDs, tornillos y estrellas son capas HTML/CSS — el PNG solo aporta el material.
