# Kenney domino pack

`kenney_domino-pack.zip` is the unmodified Kenney domino pack (CC0), the source
of the clear domino tiles packaged in `app/src/main/res/drawable-nodpi`. The
zip is kept here as provenance; only the reduced tile exports travel inside the
APK, with the license in `app/src/main/assets/licenses/kenney-domino-pack.txt`.
