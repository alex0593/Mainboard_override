# Reference artwork

Removed-background PNG drafts used as visual references while editing board and
sprite artwork. They are inputs for the generation workflow, not packaged
resources: Android only ships the reduced exports in
`app/src/main/res/drawable-nodpi`.

- `Firewall-removebg-preview.png` — firewall chip reference.
- `hp-removebg-preview.png` — honeypot reference.
